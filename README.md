# 🌿 GlowCare - Skincare Landing Page

GlowCare is a responsive skincare product landing page inspired by MamaEarth, built using **HTML** and **Tailwind CSS**. This project highlights a clean layout, modern design, and mobile-friendly responsiveness.

## 🔧 Features

- ✅ Hero section with promotional content and CTA (Call to Action)
- ✅ Product highlights: Natural ingredients, dermatologist approved, eco-friendly
- ✅ Customer testimonials with real photos and quotes
- ✅ Final call to action section for user engagement
- ✅ Mobile-responsive layout with Tailwind utility classes
- ✅ Logo and brand name ("GlowCare") displayed on top-left for identity

## 🎨 Layout & Design Decisions

- **Tailwind CSS** was chosen for rapid styling and responsiveness.
- Used `flex` and `grid` utilities for structured layout.
- Gradients and soft shadows were applied to enhance visual hierarchy.
- Font used: `Inter` from Google Fonts for clean and modern readability.
- Color palette: Natural greens and whites to match an eco-conscious skincare theme.

## 🧩 Components Used

- Hero Section with heading, description, image, and CTA
- Feature cards with images and benefits
- Testimonial cards with customer names and quotes
- Footer CTA encouraging user conversion
- Logo placed using flex in top-left (optional: can be added inside a nav or header)

## 🚀 How to Run

Just open `index.html` in any browser. No additional setup or frameworks are needed.
